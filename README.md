# Vajra-Shield (C Implementation)

Vajra-Shield is a Proactive Forensic Blackbox for Universal Safety. This repository contains the edge-AI terminal simulation written entirely in pure C.

## Features Simulated
- **Sensor Fusion:** Simulates accelerometer and biometric data to detect physical chaos.
- **The Adrenaline-Stillness Paradox:** Logic that triggers SOS if heart rate is high but the victim is completely stationary (e.g., pinned or tied up).
- **Aperiodic Chaos Detection:** Distinguishes between rhythmic movement (like jogging) and violent struggle using magnitude thresholds simulating FFT filtration.
- **Duress Protocol:** Simulated Hostage Mode using a Safe-PIN `1234` vs a Duress-PIN `4321`.
- **Digital DNA Sweeping:** Mock detection of nearby Bluetooth MAC addresses.
- **Forensic Vault:** Mock hashing of distress data for SpacetimeDB ingestion.

## Build and Run (Windows)
1. Ensure you have GCC / MinGW installed.
2. Double click the `build.bat` file to compile.
3. Run `bin/vajra_shield.exe` to start the interactive test suite.
